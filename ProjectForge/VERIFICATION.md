## 验证边界

- [中央宿主测试](tests/central-host.test.js:10) 真实运行中央加载器和调用桥，但替换审批、日志、知识库、定时调度等无关宿主依赖，仅发现两个新插件。未启动整套生产中央服务器，也未验证真实 LLM 会话、生产审核规则、远程节点和 Embedding 服务的在线可用性。
- 本机无 Cargo，Rust 实际编译/执行测试跳过；并未将它记为通过。索引器运行和 Rust 源码符号分析已通过，但未从源码重新构建索引器。
- 生产服务账户的 Windows 回收站策略须按部署账户复核；本机交互账户实际回收已通过，权限失败路径使用故障注入验证。
- 未进行断电硬件测试；恢复日志测试模拟中断状态及记录失败，不代表文件系统与数据库具有跨资源原子事务。
- 工程代码执行不是安全沙箱；最小环境变量、超时和取消不限制被测代码的操作系统账户权限。
- 停用工作区保持原有工程只读语义，不是多租户隔离。静态状态是全局占位符，不根据 Agent 身份实施授权。
- 默认配置未授权真实工作目录，也未开启可信执行；实际部署仍须管理员编辑 [config.env](config.env) 并重启中央服务。
