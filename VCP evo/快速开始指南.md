# AI创造力涌现引擎 - 快速开始指南

## 📋 项目概览

本项目实现了一个完整的 AI 创造力涌现引擎，通过三个协同工作的插件在不同层面激发和评估 AI 的创造力。

### 核心组件

| 插件 | 类型 | 功能 | 状态 |
|------|------|------|------|
| **ConceptCollider** | 同步插件 | 概念碰撞，生成创新组合 | ✅ 已设计 |
| **CreativityInjector** | 消息预处理器 | 注入创造性思维触发器 | ✅ 已设计 |
| **CreativityScorer** | 静态/定时插件 | 评估创造力表现 | ✅ 已设计 |

## 🎯 核心特性

### 1. ConceptCollider（概念碰撞器）

**三种碰撞模式：**
- 🎭 **Metaphor（隐喻模式）** - 寻找深层相似性
- 🔧 **Practical（实践模式）** - 探索跨界应用
- 🎨 **Artistic（艺术模式）** - 创造概念艺术

**调用示例：**
```
<<<[TOOL_REQUEST]>>>
tool_name:「始」ConceptCollider「末」,
concept_a:「始」区块链「末」,
concept_b:「始」农业「末」,
collision_mode:「始」practical「末」
<<<[END_TOOL_REQUEST]>>>
```

### 2. CreativityInjector（创造力注入器）

**注入模式：**
- 🔀 **metaphor** - 隐喻类比
- 🌐 **crossDomain** - 跨域思维
- 🔗 **combination** - 概念组合
- 🔄 **reversal** - 反向思考
- ⛓️ **constraint** - 约束激发

**自动触发：**
- 每 N 条消息自动注入一次
- 随机性强度可配置（0.0-1.0）
- 非侵入式设计，保留原始消息

### 3. CreativityScorer（创造力评分器）

**三维评估：**
- 📊 **新颖度** (40%权重) - 与历史内容的差异度
- 🔀 **跨域性** (35%权重) - 涉及领域的广度和深度
- ✅ **可行性** (25%权重) - 想法的实际可行性

**自动报告：**
```
{{CreativityMetrics}}
当前创造力指标：
━━━━━━━━━━━━━━━━━━
📊 新颖度：★★★★☆ (0.78)
🔀 跨域性：★★★☆☆ (0.65)
✅ 可行性：★★★★★ (0.92)
━━━━━━━━━━━━━━━━━━
综合创造力指数：0.77 (高)
```

## 🔧 配置参数

### ConceptCollider 配置

```env
CONCEPT_POOL_PATH=./data/concept_pool.json
INSPIRATION_VAULT_PATH=./data/inspiration_vault.json
SIMILARITY_THRESHOLD=0.3
MAX_INSIGHTS_PER_COLLISION=5
```

### CreativityInjector 配置

```env
RANDOMNESS_LEVEL=0.5          # 0.0-1.0，控制注入强度
TRIGGER_FREQUENCY=3           # 每N条消息触发一次
MAX_INJECTION_LENGTH=200      # 触发器最大长度
ENABLED_MODES=metaphor,crossDomain,combination
```

### CreativityScorer 配置

```env
NOVELTY_WEIGHT=0.4           # 新颖度权重
CROSS_DOMAIN_WEIGHT=0.35     # 跨域性权重
FEASIBILITY_WEIGHT=0.25      # 可行性权重
SCORING_INTERVAL=3600        # 评分间隔（秒）
```

## 📊 数据文件说明

### concept_pool.json
存储跨领域概念库，供 CreativityInjector 和 ConceptCollider 使用。

**结构：**
- `domains`: 知识领域数组，每个包含领域名称和概念列表
- `metaphors`: 隐喻词汇库

### inspiration_vault.json
存储所有概念碰撞的结果。

**结构：**
- `collisions`: 碰撞结果数组
- `metadata`: 统计元数据

### creativity_history.json
存储所有 AI 输出的评分历史。

**结构：**
- `conversations`: 对话记录数组
- `statistics`: 统计信息

## 🐛 常见问题

### Q1: ConceptCollider 返回空结果
**A:** 检查 `data/concept_pool.json` 是否存在且格式正确。

### Q2: CreativityInjector 从不触发
**A:** 检查 `TRIGGER_FREQUENCY` 配置，确认消息计数器正常工作。

### Q3: Python 模块找不到
**A:** 确保在正确的目录下安装了 `requirements.txt` 中的依赖。

### Q4: 权限错误
**A:** 检查 `data/` 目录的读写权限。

## 📈 性能优化建议

1. **概念库优化**
   - 定期更新概念库内容
   - 根据使用频率调整概念权重

2. **历史库管理**
   - 超过1000条记录时自动归档
   - 考虑使用数据库替代JSON

3. **缓存机制**
   - 缓存频繁使用的概念组合
   - 减少重复的语义分析计算
