# AI创造力涌现引擎 - 部署指南

## 📋 前置要求

- **Node.js**: v16.0.0 或更高版本
- **Python**: 3.8 或更高版本
- **npm**: 用于安装 Node.js 依赖
- **pip**: 用于安装 Python 依赖

## 🚀 快速部署

### 步骤 1: 安装 Node.js 依赖

```bash
cd Plugin/ConceptCollider
npm install
```

**预期输出**: 成功安装 `natural` 和 `compromise` 包

### 步骤 2: 安装 Python 依赖

```bash
# CreativityInjector
cd ../CreativityInjector
pip install -r requirements.txt

# CreativityScorer
cd ../CreativityScorer
pip install -r requirements.txt
```

**预期输出**: 成功安装所有 Python 依赖包

### 步骤 3: 验证数据文件

确认以下数据文件存在于 `data/` 目录：

```bash
cd ../../
ls data/
```

应该看到：
- `concept_pool.json`
- `inspiration_vault.json`
- `creativity_history.json`

### 步骤 4: 测试插件

#### 测试 ConceptCollider

```bash
echo '{"concept_a":"人工智能","concept_b":"音乐","collision_mode":"artistic"}' | node Plugin/ConceptCollider/collider.js
```

**预期输出**: JSON 格式的碰撞结果，包含多个创意洞见

#### 测试 CreativityInjector

```bash
echo '{"content":"如何创新产品设计？"}' | python Plugin/CreativityInjector/injector.py
```

**预期输出**: JSON 格式的处理结果（可能包含或不包含注入的触发器，取决于计数器）

#### 测试 CreativityScorer

```bash
echo '{"content":"这是一个融合了量子计算和艺术创作的创新想法"}' | python Plugin/CreativityScorer/scorer.py
```

**预期输出**: JSON 格式的评分报告，包含三维度评分

## ⚙️ 配置调整

### ConceptCollider 配置

编辑 `Plugin/ConceptCollider/config.env`:

```env
# 调整每次碰撞生成的洞见数量（默认 5）
MAX_INSIGHTS_PER_COLLISION=5

# 调整概念相似度阈值（默认 0.3）
SIMILARITY_THRESHOLD=0.3
```

### CreativityInjector 配置

编辑 `Plugin/CreativityInjector/config.env`:

```env
# 调整随机性强度：0.3=温和, 0.5=中度, 0.8=激进
RANDOMNESS_LEVEL=0.5

# 调整触发频率：每 N 条消息触发一次
TRIGGER_FREQUENCY=3

# 启用的注入模式
ENABLED_MODES=metaphor,crossDomain,combination
```

### CreativityScorer 配置

编辑 `Plugin/CreativityScorer/config.env`:

```env
# 调整评分权重（总和应为 1.0）
NOVELTY_WEIGHT=0.4
CROSS_DOMAIN_WEIGHT=0.35
FEASIBILITY_WEIGHT=0.25

# 调整评分间隔（秒）
SCORING_INTERVAL=3600
```

## 🔌 集成到 VCP 服务器

### 方法 1: 手动注册

在 VCP 服务器的配置文件中添加插件路径：

```json
{
  "plugins": [
    {
      "name": "ConceptCollider",
      "path": "./Plugin/ConceptCollider",
      "enabled": true
    },
    {
      "name": "CreativityInjector",
      "path": "./Plugin/CreativityInjector",
      "enabled": true
    },
    {
      "name": "CreativityScorer",
      "path": "./Plugin/CreativityScorer",
      "enabled": true
    }
  ]
}
```

### 方法 2: 自动发现

将插件目录放在 VCP 服务器的 `plugins/` 目录下，服务器会自动扫描并加载。

## 🛠️ 故障排查

### 问题 1: Node.js 依赖安装失败

**症状**: `npm install` 报错

**解决方案**:
```bash
# 清除缓存
npm cache clean --force

# 重新安装
npm install
```

### 问题 2: Python 依赖安装失败

**症状**: `pip install` 报错

**解决方案**:
```bash
# 升级 pip
python -m pip install --upgrade pip

# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题 3: 插件运行时找不到数据文件

**症状**: 插件报错 "找不到 concept_pool.json"

**解决方案**:
```bash
# 检查数据文件是否存在
ls data/

# 如果不存在，从模板创建
# 参考 插件实现文件清单_续.md 中的数据文件模板
```

### 问题 4: 权限错误

**症状**: 无法写入数据文件

**解决方案**:
```bash
# Linux/Mac
chmod -R 755 data/

# Windows: 右键点击文件夹 -> 属性 -> 安全 -> 编辑权限
```

