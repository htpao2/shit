# VCP 推理增强插件系统 - 集成测试方案

## 1. 测试概述

本测试方案针对四个推理增强插件的功能验证和集成测试，确保各插件独立运行正常，且能协同工作。

```bash
# Node.js环境
node --version  # >= 14.0.0

# Python环境
python --version  # >= 3.8

cd Plugin/KnowledgeIndexer
pip install -r requirements.txt

cd ../ReasoningTracer
```

## 4. 集成测试

### 4.1 完整推理流程测试

**测试场景**: 模拟完整的推理增强流程

**步骤1**: 更新知识索引
```bash
cd Plugin/KnowledgeIndexer
echo "{}" | python knowledge_indexer.py > ../../test_results/kg_result.json
```

**步骤2**: 执行推理分析
```bash
cd ../OmniscientReasoner
echo '{"query":"如何提高记忆效率？","reasoning_mode":"all"}' | \
  node omniscient_reasoner.js > ../../test_results/reasoning_result.json
```

**步骤3**: 评估置信度
```bash
cd ../ConfidenceEstimator
# 从步骤2的结果中提取reasoning_result
cat ../../test_results/reasoning_result.json | \
  jq '.result' | \
  jq '{reasoning_result: .}' | \
  node confidence_estimator.js > ../../test_results/confidence_result.json
```

**步骤4**: 追踪记录
```bash
cd ../ReasoningTracer
# 组合前面的结果创建追踪请求
cat > trace_input.json << 'EOF'
{
  "reasoning_id": "R-INTEGRATION-001",
  "query": "如何提高记忆效率？",
  "reasoning_steps": [
    {"step": 1, "type": "deductive", "description": "基于记忆规律"},
    {"step": 2, "type": "inductive", "description": "总结成功案例"}
  ],
  "result": "使用间隔重复法",
  "confidence": 0.85
}
EOF

cat trace_input.json | python reasoning_tracer.py > ../../test_results/trace_result.json
```

**验证集成效果**:
```bash
# 检查所有输出文件
ls -la test_results/

# 验证知识图谱被推理器使用
grep -q "knowledge_base_status" test_results/reasoning_result.json && echo "✓ 知识图谱已集成"

# 验证置信度评估完成
grep -q "overall_confidence" test_results/confidence_result.json && echo "✓ 置信度评估完成"

# 验证推理追踪成功
grep -q "mermaid_diagram" test_results/trace_result.json && echo "✓ 推理追踪完成"
```

### 4.2 数据流一致性测试

**测试目标**: 验证插件间数据传递的正确性

```bash
# 创建测试脚本
cat > test_data_flow.sh << 'EOF'
#!/bin/bash

# 1. 知识索引
echo "Step 1: Knowledge Indexing..."
cd Plugin/KnowledgeIndexer
KG_OUTPUT=$(echo "{}" | python knowledge_indexer.py)
echo "$KG_OUTPUT" > ../../test_results/step1_kg.json

# 2. 推理分析
echo "Step 2: Reasoning..."
cd ../OmniscientReasoner
REASONING_OUTPUT=$(echo '{"query":"测试数据流"}' | node omniscient_reasoner.js)
echo "$REASONING_OUTPUT" > ../../test_results/step2_reasoning.json

# 3. 提取推理结果
REASONING_RESULT=$(echo "$REASONING_OUTPUT" | jq '.result')

# 4. 置信度评估
echo "Step 3: Confidence Assessment..."
cd ../ConfidenceEstimator
CONFIDENCE_OUTPUT=$(echo "{\"reasoning_result\": $REASONING_RESULT}" | node confidence_estimator.js)
echo "$CONFIDENCE_OUTPUT" > ../../test_results/step3_confidence.json

# 5. 推理追踪
echo "Step 4: Reasoning Trace..."
cd ../ReasoningTracer
TRACE_INPUT=$(cat << TRACEJSON
{
  "reasoning_id": "R-DATAFLOW-001",
  "query": "测试数据流",
  "reasoning_steps": [{"step":1,"type":"deductive","description":"测试"}],
  "result": "测试结果",
  "confidence": 0.8
}
TRACEJSON
)
TRACE_OUTPUT=$(echo "$TRACE_INPUT" | python reasoning_tracer.py)
echo "$TRACE_OUTPUT" > ../../test_results/step4_trace.json

echo "Data flow test completed. Check test_results/ directory."
EOF

chmod +x test_data_flow.sh
./test_data_flow.sh
```

**验证点**:
- ✓ 所有步骤成功执行
- ✓ 数据格式符合规范
- ✓ 无数据丢失或损坏
- ✓ 置信度值在合理范围内

## 5. 性能测试

### 5.1 响应时间测试

```bash
# 测试各插件的响应时间
for plugin in KnowledgeIndexer OmniscientReasoner ConfidenceEstimator ReasoningTracer; do
  echo "Testing $plugin..."
  time (echo '{"query":"性能测试"}' | \
    python Plugin/$plugin/*.py 2>/dev/null || \
    node Plugin/$plugin/*.js 2>/dev/null)
done
```

**性能目标**:
- KnowledgeIndexer: < 30秒 (取决于文档数量)
- OmniscientReasoner: < 10秒
- ConfidenceEstimator: < 3秒
- ReasoningTracer: < 5秒

### 5.2 并发测试

```bash
# 模拟多个并发推理请求
for i in {1..5}; do
  (echo "{\"query\":\"并发测试$i\"}" | \
    node Plugin/OmniscientReasoner/omniscient_reasoner.js > \
    test_results/concurrent_$i.json) &
done
wait

# 检查所有请求是否成功
for i in {1..5}; do
  grep -q '"status":"success"' test_results/concurrent_$i.json && \
    echo "✓ Request $i succeeded"
done
```

## 8. 持续集成建议

如果使用CI/CD系统，可以配置自动化测试：

```yaml
# .github/workflows/plugin-test.yml
name: Plugin Integration Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Setup Node.js
        uses: actions/setup-node@v2
        with:
          node-version: '16'
      
      - name: Setup Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.9'
      
      - name: Install dependencies
        run: |
          pip install -r Plugin/KnowledgeIndexer/requirements.txt
          pip install -r Plugin/ReasoningTracer/requirements.txt
      
      - name: Run unit tests
        run: ./run_all_tests.sh
      
      - name: Run integration tests
        run: ./test_data_flow.sh
```
